إعداد GitHub للبحث

الهدف إنشاء سجل بحث منظم وقابل للتتبع، مع فصل واضح بين الملفات العامة والبيانات السرية.

1

مستودع خاص للبحث

يحوي خطة البحث، سجل القرارات، الأكواد، قوالب التحليل، والملفات التي يسمح نظام الجامعة بحفظها.

2

GitHub Project لمراحل الرسالة

حقول مقترحة: المرحلة، الأولوية، الموعد، الحالة، نوع المخرج، وملاحظات المشرف.

3

Issue لكل مهمة قابلة للإغلاق

مثال: مراجعة مفهوم رئيس، اختبار صدق الأداة، أو معالجة ملاحظة الفصل الثالث.

4

Release عند كل نسخة معتمدة

ارفقي نسخة PDF أو DOCX المعتمدة بعنوان واضح مثل Proposal-v1 أو Thesis-draft-v3.

5

صفحة عامة للمخرجات فقط

تنشر الملخص، العرض، الأدوات العامة، أو النتائج المصرح بها بعد إخفاء أي بيانات تعريفية.
